--- bunker fs mount --help ---
Mount the bunkerd WebDAV surface at <mountpoint> using the bunker-fs FUSE client.

The mountpoint is created private (0700) and an existing wider mode is tightened;
--allow-other is STRIPPED (accepted and ignored), never honoured or refused.

The cache is bounded and content-addressed: 256 MiB by default, evicted
least-recently-HIT first at insert, and BYPASSED (read straight through, nothing
cached) when nothing can be evicted — a read never fails for a local-capacity
reason. The kernel keeps no file data (FOPEN_DIRECT_IO + ExplicitDataCacheControl),
so the cache figure `bunker fs status` reports is the only local copy.

The mountpoint stays mounted when the transport dies: every operation fails loudly
within the 30 s deadline with a named cause, and recovery is one command.

Usage:
  bunker fs mount <mountpoint> [flags]

Flags:
      --allow-other                        requested and STRIPPED: the mountpoint stays private 0700
      --cache-dir string                   override the cache directory (default $XDG_CACHE_HOME/bunker/fs/<mount-id>)
      --cache-max-age duration             backstop TTL for a cache entry (default 1h0m0s)
      --cache-max-entries int              the ENTRY bound of the cache directory (a byte bound alone does not bound a directory: BFS-031) (default 16384)
      --cache-max-entry-bytes int          a single file larger than this is never cached (default 67108864)
      --cache-max-inflight int             how many staged (unpublished) blobs may hold bytes at once (default 2)
      --cache-max-size int                 hard cap on cache bytes on this client (0 disables the cache) (default 268435456)
      --concurrency int                    maximum requests in flight (the measured lever: 25x concurrency beat MaxConnsPerHost=1 by 25x) (default 25)
  -h, --help                               help for mount
      --hot.backoff-base-ms int            first retry delay in milliseconds (P-10) (default 250)
      --hot.backoff-factor float           backoff growth factor (P-10) (default 2)
      --hot.backoff-jitter string          full|none: full jitter by default, so N mounts cannot return together (P-10) (default "full")
      --hot.backoff-max-ms int             retry delay cap in milliseconds; may not exceed --op-timeout's 30s (P-10) (default 30000)
      --hot.decay float                    (0,1]: the decay factor applied per step; 1.0 means no decay (H-3) (default 0.9)
      --hot.decay-step duration            the interval one --hot.decay step covers (H-3) (default 5m0s)
      --hot.edit-weight float              popularity weight of an EDIT touch; must exceed the read weight (H-2) (default 8)
      --hot.enabled                        arm the hot-file refresh (performance-only; correctness never depends on it)
      --hot.flush-interval duration        how often a dirty tracker is persisted (H-21) (default 30s)
      --hot.max-concurrent-refresh int     maximum concurrent refreshes; clamped to the pool share and reported (Q-7/P-4) (default 2)
      --hot.max-entries int                the tracker's ENTRY bound (H-7) (default 4096)
      --hot.max-file-bytes int             the size rule: a file at or below this is refreshable, above it is never pulled (S-1, inclusive per S-2) (default 8388608)
      --hot.max-tracker-bytes int          the tracker's BYTE bound; both are enforced (H-8) (default 1048576)
      --hot.pool-pressure-ticks int        consecutive ticks of foreground slot starvation before the hot path stops itself (P-19) (default 5)
      --hot.pool-share string              the share of the client's pool a refresh may hold, as a fraction (P-3) (default "1/8")
      --hot.queue-depth int                refresh queue depth; when full the LOWEST-SCORING item is displaced, never the oldest (Q-1/Q-3) (default 256)
      --hot.queue-max-wait duration        a queued item older than this is dropped (Q-6) (default 5m0s)
      --hot.reacquire-window duration      how long a yielded refresh may wait for its slot back (P-12) (default 30s)
      --hot.read-touch-window duration     one read touch per path per window, so chunked reads do not inflate a score (H-9) (default 5s)
      --hot.read-weight float              popularity weight of a READ touch (H-1) (default 1)
      --hot.refresh-deadline duration      an upper bound on one refresh's life; it is abandoned at this deadline (P-11) (default 10s)
      --hot.score-ceiling float            score above which every score is halved in one pass (H-6) (default 10000)
      --hot.stop-deadline duration         the time within which a stop must be fully in force (Q-12) (default 1.5s)
      --hot.tick-interval duration         the manager's tick: yield check, expiry sweep and re-arm check (Q-14) (default 1s)
      --hot.yield-after duration           a refresh holding a slot releases it if a foreground request has waited this long (P-7) (default 250ms)
      --invalidate-idle-timeout duration   how long the pushed channel may be silent before the mount falls back to the poll (0 derives it from the heartbeat period the server declares)
      --invalidation string                auto|push|poll (auto prefers the pushed channel and DECLARES a downgrade) (default "auto")
      --max-conns-per-host int             transport connection cap (0 follows --concurrency; 1 reproduces the serial arm)
      --no-cache                           disable the cache (same as --cache-max-size 0)
      --no-snapshot                        disable the one-call node-tree snapshot (every directory read falls back to PROPFIND)
      --on-conflict string                 refuse|overwrite-if-unchanged (default "refuse")
      --password string                    HTTP Basic password
      --poll-interval duration             declared poll period (default 2s)
      --url string                         WebDAV surface root, e.g. http://127.0.0.1:18481/dav (required)
      --user string                        HTTP Basic username
      --verbose                            log the client's decisions to stderr
      --write-buffer-max-bytes int         bound on one open write handle's local buffer (default 268435456)

Global Flags:
      --config string          CLI config file. Precedence: --config > $BUNKER_HOME/config.yaml > $HOME/.bunker/config.yaml. NOTE: 'bunker systemd install --config' means the DAEMON config and shadows this flag
      --daemon-config string   DAEMON config file for the local-file command defaults (audit --path, registry compact --path). Precedence: --daemon-config > $BUNKERD_CONFIG > /etc/bunkerd/config.yaml. An explicit --path on those commands always wins
