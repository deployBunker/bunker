1. Executive Summary

Bunker is a multi-tenant Docker host provisioning platform for AI agents. It provides a gRPC + REST API that spawns isolated, resource-enforced Docker environments — each with its own Linux user, SSH access, Cloudflare tunnel, and cgroup limits. Think "VPS-as-a-service for agents" — one CLI to provision, manage, and destroy agent workspaces across multiple physical hosts.

2. Problem Statement

AI coding agents need isolated environments to build, test, and run code. Existing solutions (GitHub Codespaces, Docker-in-Docker, manual VPS provisioning) either lack isolation guarantees, require manual SSH setup, or can't be provisioned programmatically. Bunker solves this by providing a single API that:

  • Spawns rootless Docker environments with per-agent Linux users
  • Enforces CPU/memory/disk/process limits via cgroups
  • Auto-provisions Cloudflare tunnels for public access
  • Supports multi-host management from one CLI
  • Provides SSH + Docker exec + SSHFS mount for agent tool access

7. Security Model

Two-Tier Authentication

TierMethodUse Case
Top-levelStatic pre-shared token (BUNKER_TOKEN)bunkerd API access: spawn, destroy, list all agents
Agent-scopedJWT sub-keys (Ed25519), scope: single agent IDPer-agent access: exec, metrics, heartbeat — only own agent

Transport Security

ModeFlagWhen
Self-signed TLS--tls-mode=self-signedDevelopment, internal networks
Let's Encrypt--tls-mode=letsencryptProduction with public domain
mTLS--tls-mode=mtlsZero-trust deployments, cert-based agent auth

All modes use certmagic for auto-renewal. Client CLI supports --tls-insecure for self-signed certs.

11. Multi-Host Management

Bunker supports managing multiple bunkerd instances from a single CLI:

$ bunker connect bunker-mvp.example.com:9090 --token sk-xxx
Connected to bunker-mvp — server v0.1.0, 3 agents running

$ bunker connect bunker-prod.example.com:9090 --token sk-yyy
Connected to bunker-prod — server v0.1.0, 12 agents running

$ bunker use bunker-mvp
Active server: bunker-mvp

$ bunker status --all
🏠 bunker-mvp          ONLINE  3 agents  CPU 12%  MEM 4.2/16 GB
🏭 bunker-prod         ONLINE  12 agents CPU 67%  MEM 28/64 GB
☁️  bunker-staging       OFFLINE — connection refused

Server configuration stored in ~/.bunker/config.yaml. The --server flag overrides the active server for one-off commands.
