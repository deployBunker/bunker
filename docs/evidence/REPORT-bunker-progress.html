3 · What the work kept teaching

the lessonthe evidence behind it
The rows keep being SMALLER than the defectsSix of the rows that landed came back worse or different than filed. BFS-021's fix contained the filed defect (lost bytes with a success exit code). BFS-020's 'rename race' hid a zero-byte file that was never published at all. BFS-017's 'noisy guard' hid a green with no test verdict. A filed magnitude is an estimate until someone measures it through the real path — so every brief now demands the measurement AND the mutation that makes the cell fail.
A control that only turns things RED is not enoughThe strong rows ship an ATTRIBUTION cell that must stay GREEN under each mutation. That is what makes cells independent: exclusive-size flips the bound comparison to `<` and reds its own two cells while the no-partial-read cell stays green. Without it a mutation can blanket-red the suite and masquerade as coverage.
A guard whose state is not reported is not a guardApplied unprompted by the P1 boot-destroy guard, which announces at every boot whether it is armed and where its threshold sits — 'so an operator can see it without reading the source'. Same law as a bound that does not bound (031) and a counter that cannot move (032).
A figure that cannot move must be absent WITH A REASONThe observability row requires every bound to be counted and the census to FAIL when a figure cannot move — an unexplained null on a live row is junk to be cleaned, not a zero.
Verify the SPECIFIC thing, never a proxyA landing script that mixes `&&` (merge) with `;` (report) lets a failed --ff-only print success; a read-back of HEAD passes while the code is unmerged. Assert THE COMMIT is an ancestor of origin/main AND THE FILE is in its tree. Twice this session that read-back caught a refused push (a GitHub workflow-scope rejection) that would otherwise have been claimed as landed.
Measuring the current tree beats quoting the historical numberBFS-031 was filed at 29.97× and measures 7.78× today, because the code now logs one line per refused path instead of ~40. The worker explained the gap rather than quoting the better headline.

The one-line summary of the whole line of work

A filed defect's magnitude and scope are estimates until someone measures them through the real path — and the workers, given a live arm and a negative control, consistently found more than the row asked for and chose the measured number over the impressive one. Six rows came back worse than filed; every one of those was caught by a test that could fail, not by review.
