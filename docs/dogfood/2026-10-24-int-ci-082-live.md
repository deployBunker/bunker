- `session_denied=true`
- SSH exit 254
- one attempt only
- attempt latency 2,363 ms
- per-attempt budget 10,000 ms
- the INT-DEMO-001 diagnostic in the caller output

The full spawn wall time was 21,041 ms because it includes provisioning and rollback; that is not the probe latency. The probe itself failed on its first bounded attempt in 2,363 ms and did not consume a scaled retry budget.
